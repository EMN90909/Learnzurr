# Security

Global protections include JWT verification, role checks, Redis rate limits, CORS restriction, panic recovery, input sanitization, AES-256 encryption hooks, audit logging, fraud flags, IP blacklist, safe errors, file MIME validation, no localStorage tokens, httpOnly refresh cookies, prepared statements, RLS, idempotent payment callbacks, webhook verification, and sandbox resource isolation.

Each engine includes 50 security rule entries in its `security.go` file.
