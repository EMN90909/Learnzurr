# Engines

Learnzur includes Gamfy, Mearn, LMS, Classroom, San, Lanmat, Notify, Media, Find, and Flag engines. Each engine has handler, service, repository, models, security, and speed files. Each engine owns a Redis namespace and a database table group.

## Creation Studio expansion

Learnzur Media now supports child-friendly animation and beat creation flows. Animation tools are grouped into Timeline and Frames, Animation Control, Object Transformations, Character and Rigging, Advanced Effects, Editing Workflow, Audio, Preview/Export/Sharing, and Special Creative Tools. Learners aged 8-12 see simple language and guided presets first. Learners aged 13-18 see advanced controls such as graph editor, interpolation, rigging, particles, virtual camera, export formats, expressions, and scripting.

Beat Making is available under Learner Create and can publish reviewed beat listings to Lanmat. Beat projects include tempo, step sequencer, loop builder, piano roll, mixer, EQ, compression, effects, preview clips, license type, price guidance, and parent/teacher review before marketplace sale.
