# Learnzur Admin Security Rules

Admin follows the uploaded admin spec: role guard, backend authorization, Supabase-backed access, audit logs, reason-required sensitive actions, pagination, safe filters, RLS, HTTPS, secure cookies, and no localStorage tokens.

Sensitive actions include payouts, treasury changes, bans, teacher approval/rejection, marketplace moderation, contest winners, event check-ins, NGO approvals, feature flags, security blacklist changes, and notification blasts.
